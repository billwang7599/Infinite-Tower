# The 2D overworld (archived)

The overworld used to be drawn flat, straight down. The HD-2D one replaced it because the user prefers it ("i think
3d view is much cooler actually. can we make that default? and archive 2d view for now").

The last commit with both is the git tag `archive/overworld-2d`. Bringing it back means restoring its flat drawing
beside today's, a switch between the two (a setting, if it's for players), and the margin round the map it drew.
Both share the tile looks, the chibi and the enemies' sprites; anything added only to the 3D world has no flat
drawing.
